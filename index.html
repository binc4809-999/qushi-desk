一、项目一句话

五饼二鱼把「想法 → 可运行脚本 → 回测报告 → 公网看板」做成可交付产品；同时用同一套工程能力，帮客户搞定海外云主机、合规跨境网络、自建远程办公环境等 AI 可加速的数字化基建，缩短从需求到上线的时间。

二、为什么现在做

  1. 投研交付缺口大：基金经理与交易团队有想法，但缺工程闭环；本站已证明「脚本结果上墙」可行。
  2. AI 降低定制成本：策略梳理、运维脚本、文档与排障可用 AI 加速，小团队也能接多单。
  3. 跨境协作刚需真实：研究机、行情源、开源工具常在海外；客户需要稳定、可审计的云主机与远程访问，而不是零散教程。
  4. 可复制 SKU：投研看板是高客单定制；云/VPN/远程桌面是标准化交付，现金流更稳。

三、业务矩阵（围绕本站辐射）

A · 核心

五饼二鱼研究台

策略回测报告、买卖点看板、选股池、脚本心跳。面向专业投资者的定制化投研工程与专属看板交付。

  • 高净利回测报告上墙
  • 监控 / 预警 / 运行态
  • 按品种·周期·风控定制

B · AI 工程

想法快速落地

用 AI 压缩「口述需求 → 代码 → 回测 → 文档」链路，接小型自动化、数据管道、内部工具单。

  • 策略 / 爬虫 / 报表自动化
  • 邮件与预警接入
  • 数据契约与发布流水线

C · 云基建

海外云服务器代购与加固

协助选型、下单、初始化海外 VPS/云主机（AWS / GCP / 主流 VPS），交付可登录的加固环境与基础监控。

  • 账号与账单协助（客户主体）
  • 系统加固、密钥、备份
  • 量化研究机 / 跳板机模板

D · 跨境网络

合规用途的 VPN / 专线方案

为跨境办公、学术与研发协作提供合法用途下的节点部署、客户端配置与运维文档（不提供违法用途指导）。

  • 自建节点 / 商业线路选型建议
  • 多端配置与故障排查
  • 团队账号与审计建议

E · 远程办公

自建远程连接环境

在客户云主机上搭建远程桌面 / 安全跳板（如 RDP 加固、Tailscale/自建 WireGuard、开源远程桌面方案），方便异地稳定操控研究机。

  • 一机一密、二次验证建议
  • 备份与快照策略
  • 与投研脚本同机部署可选

F · 增值

培训 · 运维包 · 白皮书

交付不止一次安装：月度巡检、告警代值守、内部培训与可对外展示的案例页（类似本站）。

  • 按月运维订阅
  • 团队内训半天档
  • 品牌研究台代建

六、众筹结构与资金用途

首期意向目标

30–80 万人民币（分档认筹）。用途不买币投机，只投产能与产品：

  • 40% 研究台产品化：多租户、权限、模板库、案例页
  • 25% 海外节点与云资源预付（可核销到客户交付）
  • 20% 交付人力与 AI 工具链（文档、工单、质检）
  • 10% 合规与法务预留（合同、隐私、出口合规咨询）
  • 5% 运营与获客（演示、内容、渠道）

支持者回馈（示意）

  • 1,000 元：鸣谢名单 + 季度进展邮件
  • 3,000 元：云主机 / VPN 配置一次优惠券
  • 10,000 元：研究台演示深度讲解 + 优先排期
  • 30,000 元：锁定一档轻量定制名额（半年内履约）
  • 80,000 元+：战略合作洽谈权与联合案例优先

回馈以服务抵扣为主，不承诺股权、不承诺投资收益。

七、12 个月里程碑

  1. Q1

    验证交付飞轮

    每月至少 2 单标准化基建交付 + 1 单研究台定制；工单与报价模板固化。

  2. Q2

    产品化研究台

    多客户配置隔离、回测报告模板库、众筹支持者专属演示通道。

  3. Q3

    基建 SKU 规模化

    云 / 远程 / 节点三套一键手册；月度运维包订阅破 20 户。

  4. Q4

    品牌与合规加固

    公开 3 个可展示案例（脱敏）；完善合同与合规清单；评估下一轮扩产。

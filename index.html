About

关于 / 能做什么

五饼二鱼是给基金经理看的研究台，不是零售荐股站。研究在本地 PyCharm 脚本里跑；结果按约定写成 JSON，推到 GitHub Pages。经理打开浏览器就能看当前买卖点、池子和脚本是否还在跑——不必登录终端，也看不到源码。

演示台是能力证明，用来获客与对接。合作路径是预约交流、看演示、再接你们的脚本与数据契约。

  1. 01

    本地研究

    选股、监控、加密预警在 PyCharm 循环里跑。

  2. 02

    数据契约

    tips / pools / charts / runners / opportunities 写入仓库。

  3. 03

    公网看板

    静态站点经 CDN 分发，阅读流量不打源站。

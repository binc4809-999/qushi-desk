# 五饼二鱼 · 邮件预警

## 目标（一句话）

**展示邮箱收到的预警内容**（主题 + 正文）。可选按 A股 / 加密 / 美股 过滤。

## 信息架构

| 栏目 | 作用 |
|---|---|
| **邮件预警**（首页） | 默认「全部」+ 分类过滤 · 时间倒序卡片 |
| **联系** | 电话 / 邮件 / 微信 / 收款 |

## 数据管道

脚本发邮件 → IMAP 入库（`ingest_mailbox.py`）→ `data/alerts.json` → 页面展示。

每条最少字段：`id` / `ts` / `title`（邮件主题）/ `body`（正文）/ `market` / `via: "mail"` / `live`。
